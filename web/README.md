Next.js + TypeScript. Fase 1: sistema de diseño (Atlas claro, Consola oscuro, 8 colores de perfil) y estructura de la pantalla de chat con datos de ejemplo.

```
cd web && npm install && npm run dev
```

La página actual de la raíz del repo no se toca hasta el paso a producción (fase 7). Para ver esta en Vercel, apuntar el Root Directory del proyecto de vista previa a `web`.
